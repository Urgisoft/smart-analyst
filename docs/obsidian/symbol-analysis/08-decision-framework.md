# 08 — The Decision Framework

> After completing sections 1-7, you have data across six dimensions. Now combine them into a position decision. The discipline is not falling in love with any single dimension.

## The six-dimension scorecard

| Dimension | Question | Reading |
|-----------|----------|---------|
| [[01-what-is-it]] | Do I understand what I'm buying? | Yes / Partially / No |
| [[02-fundamentals]] | Is the underlying quality strong? | Strong / Mixed / Weak |
| [[03-valuation]] | Am I paying a reasonable price? | Cheap / Fair / Expensive |
| [[04-technicals]] | What is price action telling me? | Bullish / Mixed / Bearish |
| [[05-sentiment-options]] | Is positioning extreme? | Balanced / Bullish / Extreme bullish / Bearish / Extreme bearish |
| [[06-structure]] | Are concentration and costs acceptable? | Clean / Concerns / Problems |
| [[07-macro-fit]] | Does environment favor this? | Tailwind / Neutral / Headwind |

## Patterns worth recognizing

### Compelling buy
Strong fundamentals + cheap valuation + bullish technicals + balanced sentiment + clean structure + macro tailwind.

Rare. When it happens, take a real position.

### Quality at fair price
Strong fundamentals + fair valuation + neutral technicals + balanced sentiment + clean structure + neutral macro.

Common for high-quality businesses. Reasonable position size; don't expect outsized returns.

### Late-cycle growth (the FTEC pattern)
Strong fundamentals + expensive valuation + bullish technicals + extreme bullish sentiment + concentrated structure + macro headwind brewing.

Hold or trim, don't add. The setup that produces the largest gains right before the largest reversals.

### Value trap
Weak fundamentals + cheap valuation + bearish technicals + bearish sentiment + structural concerns + macro headwind.

Cheap for a reason. Skip.

### Contrarian opportunity
Strong fundamentals + cheap valuation + bearish technicals + extreme bearish sentiment + clean structure + macro turning supportive.

Rare. When found, the opportunity is real. Requires patience as sentiment usually takes time to shift.

### Skip
Most setups don't fit any of the above patterns clearly. When in doubt, skip. There's always another opportunity.

## Position sizing by conviction

| Conviction level | Position size | When |
|------------------|---------------|------|
| Highest | Up to portfolio max (5-10% single position) | Compelling buy + macro tailwind + all dimensions aligned |
| High | 3-5% of portfolio | Quality at fair price + strong macro fit |
| Moderate | 1-3% of portfolio | Mixed signals but tilted positive |
| Low / Testing | 0.5-1% of portfolio | Hypothesis test, expect to lose this |
| Skip | 0% — no position | Mixed signals without clear edge, or warnings on key dimensions |

> Don't confuse "interesting" with "investable." Most symbols you analyze should result in a Skip decision. If everything looks like a buy to you, you're not being selective enough.

## Pre-execution sanity checks

- [ ] Have I checked all six dimensions, not just the ones that confirm my prior belief?
- [ ] Would I be willing to hold this through a 20% drawdown without selling?
- [ ] Does this position fit my overall portfolio (concentration, sector exposure, etc.)?
- [ ] Am I trading on conviction or on FOMO?
- [ ] Have I defined my exit conditions in advance (price targets, stop levels, time horizon)?
- [ ] If this position goes against me by 10%, will my thesis still be valid?
- [ ] Is this position size appropriate for my conviction level?
- [ ] Am I executing during regular market hours with a limit order?

## Connection to broader system

Once you've made the decision:
- If the position fits a SignalForge strategy, log it in the strategy's trade ledger
- If the position is discretionary, log it in a separate discretionary ledger
- Track outcomes separately so you can audit your own decision quality
- After a year, you'll have data on whether discretionary analysis adds value over systematic alone
